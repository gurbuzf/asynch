# agent_workspace/

Working notes for the development work on this fork: plans, decisions, status and
task prompts. **Nothing here is part of ASYNCH itself.** The code and its documentation
(`src/`, `docs/`, `tests/`, `examples/`, `README.md`, `CHANGELOG.md`) never refer to this folder.

| File | Content |
|---|---|
| [roadmap.md](roadmap.md) | phases, working rules, open decisions |
| [work_log.md](work_log.md) | what was done in each session, newest first |
| [prompts.md](prompts.md) | ready-to-use task descriptions for the upcoming work |
| [design_io_formats.md](design_io_formats.md) | proposal: new input/output formats (YAML, link table, NetCDF), with the catalogue of all models |

All development happens on branch `modernization`. It is not merged into `master`
and no pull requests are opened.
